# 🩸 BloodNet

BloodNet is a web-based blood donation management system designed to connect donors, hospitals, and blood banks within a regional network. The system improves coordination and response time for blood requests by enabling efficient matching, communication, and tracking of donations.

---

## 🚀 Project Description

BloodNet provides a centralized platform where:
- Hospitals can create and manage blood requests
- Donors can receive notifications and respond to donation requests
- Blood banks can manage inventory and support request fulfillment
- Administrators can monitor system activity and manage users

The system also includes a donor motivation feature through a **leaderboard and award system** to encourage regular donations.

## 📌 Core Functionalities

The system includes the following main functionalities:

1. User Authentication (Register / Login / Reset Password)
2. Donor Profile Management
3. Blood Request Creation (Hospital)
4. Donor Matching and Notification System
5. Donation Tracking and History
6. Blood Bank Inventory Management
7. Leaderboard and Award System for Donors

... and more
